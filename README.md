# Quartzio

A Gantt chart library: a headless, framework-agnostic TypeScript engine with thin framework wrappers.

> Early development — not ready for use yet.

| Package                                         | Description                                                |
| ----------------------------------------------- | ---------------------------------------------------------- |
| [`@quartzio/gantt`](packages/gantt)             | Headless engine: data model, scheduling, time axis, layout |
| [`@quartzio/gantt-react`](packages/gantt-react) | React component                                            |

## Development

Requires Node 24+ and pnpm.

```bash
pnpm install
pnpm dev        # start the React playground
pnpm check      # lint, typecheck, test, build
```
